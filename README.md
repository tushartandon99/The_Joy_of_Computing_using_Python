# 🐍 The Joy of Computing using Python – Course Repository

## 📌 Overview

This repository contains all programs, assignments, and mini-projects completed as part of the **“Joy of Computing using Python”** course.

The course focuses on building strong fundamentals of Python programming along with practical problem-solving and real-world applications.

---

## 🎯 Objectives

* Learn Python programming from basics to intermediate level
* Develop logical thinking and problem-solving skills
* Work with real-world data and applications
* Understand core concepts like data structures, algorithms, and file handling

---

## ▶️ How to Run

1. Clone the repository
2. Install required libraries:

```bash
pip install pandas nltk numpy opencv-python openpyxl
```

3. Run any Python file:

```bash
python filename.py
```
